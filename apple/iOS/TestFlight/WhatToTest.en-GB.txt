This build:
[NEW] Code blocks in the agent view can wrap long lines: Markdown and text blocks wrap by default, every block has a Wrap button, and Settings ▸ Agent View picks which blocks wrap.
[NEW] Markdown in a code block can be shown rendered: press Preview in its header, and Source to go back.
[NEW] No Mac to hand? The pairing screen's **See a demo** opens Hammock with a made-up Mac: agents working and waiting, their conversations, and a scheduled task to allow.
[NEW] Settings ▸ About ▸ Acknowledgements lists the open-source software Hammock is built with, and each one's licence.
[NEW] Settings ▸ Usage Limits lists every agent your Mac can show limits for, not just Claude and Codex. For up-to-date numbers, turn on Ask each agent's service for its usage on the Mac, and show that agent's limits in the Mac's sidebar too.
[FIXED] Agent view: a message starting with ! now shows it will run as a shell command (Claude Code, Codex and Kimi), and the command and its output show as a command you ran, not as a message.
[FIXED] A Markdown file shown in the agent view inside four backticks, or tildes, no longer breaks apart at its own code blocks.
[FIXED] Agents waiting on a background job, such as a Claude Code monitor, no longer alert you every time it reports progress, only when the job finishes, the agent stops waiting or it needs you.
[FIXED] An agent at rest with shells still running no longer shows a fainter ring than one without.
[FIXED] Needs You and its notifications show what `hmk` on your Mac asks to do that only you may, and where it came from, with Allow and Deny (never Always).
[FIXED] Answering from a notification (Allow, Deny, Let View, Decline) now needs your iPhone unlocked, and with Require Face ID on it opens Hammock to ask first. Notifications take everything they show, their buttons included, only from what your Mac encrypted, and old ones replayed later show nothing. The keys for them are no longer in iPhone backups: a restored iPhone makes new ones when it next connects to each Mac.
[FIXED] Settings lists usage limits only for the agents installed on your Mac (and any you'd already switched on), not every agent Hammock knows.
[FIXED] Start an Agent names your Mac instead of calling it “This Mac”, and the Group menu shows each Group's icon.
[FIXED] The screen tile on Devices says “Display Asleep”, not “Asleep”, when the Mac is awake but its display is off.
