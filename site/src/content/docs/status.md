title: Project status
description: Hammock is in rapid development. Treat it as beta software.
---

Hammock is in rapid development, and should be treated as **beta software**.

- **Things change quickly.** New versions come out often, and features, menus, settings and `hmk` commands can change or move between them. These docs follow the latest version.
- **Expect rough edges.** Some features are newer than others, and some agents Hammock supports have been built from their source and documentation rather than tried day to day (see [Supported agents](/hammock/docs/reference/agents/)).
- **Your work is kept safe by design.** Panes live in their own processes, so a crash or an update to the app doesn't end your shells or agents. But beta software is beta software: don't let Hammock be the only place something important lives.
- **The iPhone app is in beta on TestFlight.** Keep it and the Mac app up to date together.

Bugs and ideas are welcome: see [Reporting bugs and security issues](/hammock/docs/reporting-issues/).
