Hammock is a terminal multiplexer, like tmux or Zellij, as a native app. A daemon, `hmkd`, owns your panes, so
quitting, updating or crashing the app doesn't stop them, and after a reboot your Groups come back and agents resume
their sessions. The Mac app, the iPhone app, the TUI and the `hmk` command all show the same workspace.

:::note[Project status]
Hammock is in rapid development: treat it as beta software. See [Project status](/hammock/docs/status/).
:::

## The main ideas

<CardGrid>
	<Card title="Groups, tabs and panes" icon="seti:folder">
		A Group for each piece of work, with its own tabs, split and floating panes. [The workspace](/hammock/docs/workspace/)
	</Card>
	<Card title="An agent cockpit" icon="rocket">
		See at a glance which agent is working, which needs you and which has finished, across every Group.
		[Agents](/hammock/docs/agents/overview/)
	</Card>
	<Card title="More than terminals" icon="laptop">
		Chromium browser, iOS Simulator, log, editor and diff panes, side by side with your shells.
		[Panes](/hammock/docs/panes/)
	</Card>
	<Card title="Agents drive it too" icon="puzzle">
		Through `hmk mcp`, agents open panes, run dev servers, check pages and tap through simulators.
		[MCP](/hammock/docs/agents/mcp/)
	</Card>
	<Card title="Finds you" icon="phone">
		A notification on the Mac you're using, or on your iPhone when you're away from it. Answer from there.
		[The iPhone app](/hammock/docs/iphone/)
	</Card>
	<Card title="Your other computers" icon="server">
		Link a Mac or a Linux server and see its Groups beside yours, and share Groups with other people.
		[Remote access](/hammock/docs/remote/)
	</Card>
	<Card title="From any terminal" icon="seti:shell">
		`hmk` drives your panes from a script or another terminal, and `hmk tui` is the whole workspace in a
		terminal. [The CLI](/hammock/docs/cli/) · [The TUI](/hammock/docs/tui/)
	</Card>
	<Card title="On a schedule" icon="clock">
		Run an agent's prompt or a command on a schedule, each run a new tab in its Group.
		[Scheduled tasks](/hammock/docs/scheduled-tasks/)
	</Card>
</CardGrid>
