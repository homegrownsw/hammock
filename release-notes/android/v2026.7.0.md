# Android 2026.7.0

## New

- An agent at rest shows a dot going round its ring while work still runs: grey for background shells, indigo for subagents.
- Send Now: touch and hold a message waiting for Claude to finish and tap Send Now to give it to Claude straight away.
- Shell commands: a command you run with ! shows its output as it runs, and stays open with its output once it's done.

## Fixed

- A message that the agent never took, such as a ! command you stopped in the terminal, no longer waits in the conversation forever.
- A notification no longer disappears when a late update about an earlier one arrives.
- A phone removed from your computer now asks you to pair it again, instead of trying to connect forever.
- Agents with subagents: messages from the agent view reach the agent even when its terminal is showing a subagent, the message box no longer fills with a subagent's details, and an agent no longer shows as working while only its subagents are.
- An agent that crashes or is killed no longer stays working or waiting for you, and a scheduled run of it ends.
- Hammock disconnects from your computer soon after you leave it, so notifications reach you when you're away from your computer instead of straight away, and it uses less battery.
- Hammock reconnects straight away after you switch between Wi‑Fi and mobile data.
- A pairing that fails, such as pairing again with an expired code, now says why on the screen you paired from.
- Pairing keeps going if you switch apps while it connects.
- Require Unlock: answering a notification opens Hammock and asks you to unlock it first, and pictures, simulators and menus shown full screen no longer appear over the lock.
- Sessions shows all of what an agent asks to run, and Allow answers only the request its card shows, never one that came after it.
- When Claude asks a question you can give several answers to, an answer you type yourself is now sent, along with the options you ticked.
