# iOS 2026.1.0

## New

- The terminal draws with Metal, the same way as on the Mac: italics, block characters, box drawing, powerline prompts, Nerd Font icons and images in the terminal now look as they do there.
- A pane's menu can copy its Claude Code session's Remote Control link, to open it on claude.ai.
- Simulator panes go full screen: the device fills your iPhone, and a touch with three fingers, or a shake, brings back its controls.

## Fixed

- Terminals keep up better with a flood of output, like a big file printed or a noisy build.
- A Mac paired from a link while another Mac is shown now sends this iPhone notifications without having to be shown first.
- A Mac you forget stops sending this iPhone notifications, if it can be reached, instead of sending ones that only say Something needs you.
- A message sent in the agent view while Hammock is reconnecting is put back in the box instead of being lost.
- After switching from Wi-Fi to cellular, or coming back to the app after a while, a connection to your Mac that had quietly dropped reconnects in seconds instead of looking connected.
- Answering a notification from another Mac from the lock screen (Allow, Deny, Let View) no longer changes which Mac the app shows.
- Dictation in a terminal no longer deletes too much when correcting itself after you’ve used the key bar’s delete or held down a keyboard’s Backspace.
- Holding Delete while sharing a Mac's screen now keeps deleting, on the on-screen keyboard as on a hardware one.
- Images a program on your Mac shows by file path, like Claude Code's, now come to your iPhone.
- Images in the terminal, like Claude Code's, no longer go missing when you open the pane on another device, resize it or reconnect.
- Images in the terminal, like Claude Code's, show as soon as they arrive, instead of only once you scroll.
- In the demo, opening a finished agent or scheduled run marks it as seen.
- In the demo, pausing a scheduled task, skipping its next run, moving a tab and changing a Group’s icon now work, and Run Now and the rest that need a Mac offer to pair one.
- Screen sharing: two fingers stay scrolling once they start, instead of switching to zooming partway through, and a pinch stays a zoom.
- Scrolling a picture shown in a terminal back into view no longer stutters.
- Tapping a notification opens its session again when it launches the app or is from another Mac, and tapping one for the same session twice works.
- Terminals keep 10,000 lines of scrollback, as the Mac's daemon does: coloured output kept only a few hundred.
- The agent view no longer goes blank in a long conversation, showing only Working… under an empty screen, when you open it or send a message.

## Internal

- Renderer benchmark: just render-bench times the Mac terminal's drawing offscreen, and HMK_DEBUG_RENDER_STATS times real draws and output parsing (#18).
- TerminalEngine.takeChanges reports the rows output changed, for the Mac's row-by-row redraw.
- TerminalImage carries the whole image, the part shown and a key, and TerminalCell has a public init, for the Metal renderer.
- TerminalLineLayout (HammockKit) lays terminal rows out for the Mac's renderer; the iPhone will use it too.
- TerminalMetalRenderer (HammockKit) draws TerminalLineLayout's rows with Metal, on the Mac and the iPhone.
- TerminalMetalRenderer.readableTexture and image(of:) read a rendered frame back (the Mac's debug snapshots and bench).
- Versions are now YYYY.N.P, one per app: joint releases at YYYY.N.0, Mac patches in between, iPhone builds under its YYYY.N.0.
