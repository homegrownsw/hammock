# iOS 2026.8.0

## New

- Agent view: a run of tool calls says what it did, such as “Read 4 files · ran 2 commands”, and how many failed.
- Agent view: an edit's diff names its file, numbers its lines, and has a button to copy it.
- Agent view: commands complete from any part of their name, and typing @ offers files from your project.
- Agent view: Latest says how many new messages came while you were reading further up, with a dot when the agent finishes or asks you something.
- Agent View: rebuilt to be much faster, so even long conversations open quickly and scroll smoothly.
- Agent view: tap the context gauge to see how many tokens are left, or to compact or clear the conversation.
- Agent view: with a hardware keyboard, press ↑ in an empty message box to bring back what you sent before.
- Agent view: with a hardware keyboard, press 1–9 to pick an answer to a prompt, ← and → to move between questions, and Esc to switch to the terminal.
- Connection status: every screen now says when Hammock is connecting to your computer or can't reach it, with Try Again, and you can pull down on Sessions or Groups to refresh.
- Copy from the terminal: touch and hold to select text, drag the handles to select more, then tap Copy.
- Files: a tab of your Mac's files as a tree; tap a file to open it beside the tree, or touch and hold to rename or move it.
- Haptics: feel a tap when you allow or deny a request, let someone join, approve a Hammock Key request or scan a pairing code.
- iPad: diff panes can show the old and new side by side when there's room.
- Key bar: a sticky ⌥ key, with symbols, Home and End a swipe away; ⌥ and a letter on a hardware keyboard send Esc and the letter.
- Live Activities: turn them on in Settings to follow your agents while you're away from your Mac, and Allow or Deny a permission without opening Hammock.
- Needs You widget: see what's waiting on you on your Home Screen or Lock Screen, and tap one to open it.
- Allow or Deny an agent's permission request right from its notification.
- Notifications name the agent, as on the Mac ("Claude finished"), and Hammock's icon counts what's waiting on you.
- Obsidian notes: the editor's Markdown preview now shows [[links]], embedded images and notes, callouts, highlights and tags as Obsidian does.
- Pinch a terminal to change the font size of every terminal.
- Run Again: when a terminal's program fails, a bar along its bottom starts it again in the same pane, and an agent's pane resumes its session.
- Screen sharing: minimize a Mac's screen to a bar that stays connected while you use the rest of Hammock, and tap it to have the screen back.
- Touch and hold a session or tab to see its screen, live, with Allow and Deny there for an agent asking permission.

## Fixed

- A message sent while a ! command runs no longer disappears from the agent view, taking the command with it.
- A message with pictures, sent while the agent works, now shows in the conversation as soon as the agent takes it, instead of waiting there until it finishes.
- A permission prompt shows what it's asking about, such as the command, even when the conversation hasn't caught up with it yet.
- Agent conversations scroll under the glass at the top of the screen, instead of stopping at a hard edge.
- Agent view: a group of tool calls keeps the last one's description beside it, not just while it runs.
- Agent view: a message that can't be sent now says so by the message box, with Retry.
- Agent view: Codex's and other agents' tool calls are summed up and read aloud by what they did, not as other tools.
- Agent view: new rows glide into view instead of jumping, and a long reply no longer blanks the conversation for a moment as it arrives.
- Agent view: VoiceOver reads each tool call as one, with what it ran, how it went and whether it's open.
- Attachments put into a message get a space either side, so they don't run into the words around them.
- Closing a tab or pane, from a swipe or any menu, now asks first when it would stop an agent at work.
- Finished notifications show the start of the agent's reply.
- Forgetting a computer and leaving a shared Group now ask first.
- Group settings: choosing a picture replaces the emoji.
- Live Activities: an agent starting work again just after it finished no longer shows a second Live Activity beside the first.
- Live Activities have a new look in your theme's colours, with your agent's logo, and fit the Dynamic Island properly.
- Markdown previews: a callout with a long title now wraps like text, instead of splitting into narrow columns.
- Selecting text in an editor, diff or files pane no longer brings up the Writing Tools button.
- Terminals show Offline above the keyboard while your keys can't reach your computer; tap it to try again.
- The agent view's send button stays visible while there's nothing to send.

## Internal

- Protocol: the daemon's RestartRemoteAccess message (hmk remote restart), unused by the phones.
- Agent view: a glide's point is kept once reached, so the keyboard going down just after can't leave a row to jump into view; the jank probe no longer counts an animated scroll's last frame as a snap.
- Files panes, the daemon's side: a new pane kind and its protocol (ListDir, FilesCommand, FilesChanged), with folders watched by FSEvents or inotify and git status colours.
- HammockKit: AppModel.needsYou and revealNeedingYou(by:), and the next_needs_you and previous_needs_you keybinds, for the Mac's Next Agent That Needs You; nothing changes on the iPhone.
- HammockKit: FolderDrop (the Mac's folder drops) and newGroup(inFolder:at:); nothing changes on the iPhone.
- HammockKit: the Mac's editor keybinds' titles say they ask which file (New Editor Tab…, Split Right with Editor…).
- Keybinds: browser_back, browser_forward and browser_reload actions (the Mac's; the iPhone doesn't use them).
- Settings ▸ Agent View no longer lists every agent it supports.
- Shared code: Move Tab Up and Down, and new keybind actions for the Mac (nothing changes on iPhone).
- Touch and hold on Sessions and Groups rows: a UIKit context menu, so tapping the preview opens the pane; roomier preview padding; an agent pane previews its conversation (AgentLease and groupMenuUIImage now public; menus shared as MenuEntry).
