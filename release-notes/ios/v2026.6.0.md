# iOS 2026.6.0

## New

- Simulator clipboard: touch and hold Type under a simulator or Android emulator to send your iPhone's clipboard to it, or copy its clipboard to your iPhone.
- Run Early: run a scheduled task now instead of at its next time, so it doesn’t run twice.

## Fixed

- The dot that goes round a resting agent's icon while its shells run is now bigger and easier to spot.
