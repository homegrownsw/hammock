# Mac 2026.8.0

## New

- Agent view: a run of tool calls says what it did, such as “Read 4 files · ran 2 commands”, and how many failed.
- Agent view: an edit's diff names its file, numbers its lines, and has Copy and Open in Diff Pane.
- Agent view: click the context gauge to see how many tokens are left, or to compact or clear the conversation.
- Agent view: commands complete from any part of their name, ↑ and ↓ choose one, and typing @ offers files from your project.
- Agent view: Latest says how many new messages came while you were reading further up, with a dot when the agent finishes or asks you something.
- Agent view: press 1–9 to pick an answer to a prompt, ← and → to move between questions, and Esc to switch to the terminal.
- Agent view: press ↑ in an empty message box to bring back what you sent before, as in a shell.
- Agent View: rebuilt to be much faster, so even long conversations open quickly and scroll smoothly.
- Agents can run a dev server or test watcher they started again, in its own pane, when it stops (the rerun_pane MCP tool).
- Browser panes: Back, Forward and Reload Page are in the Pane menu and the command palette, and you can change their shortcuts in Settings ▸ Keyboard.
- Browser panes: Open in Default Browser and Copy Address, in the Pane menu, the pane's menus and the command palette.
- Collapse, Expand and Collapse Others are in a Group's right-click menu and the command palette.
- Dragging a tab along the tab bar taps the trackpad as it passes another tab, as the sidebar does.
- Files: a folder's tree beside your panes, like an editor's file explorer, to open files in other panes, rename and move them, with the folders you open kept open.
- Finished agents in the sidebar can be dismissed one at a time: click a card's ✕, or right-click it and choose Dismiss. Needs You cards also highlight under the pointer, and VoiceOver reads each as a button.
- Drag a folder from the Finder onto the sidebar to make a Group for it, or onto a Group to open a tab there.
- Link a Computer: Search Again looks for your computers once more.
- Move Tab Up and Move Tab Down: reorder tabs from the File menu, a tab's right-click menu or the command palette, and give them shortcuts in Settings ▸ Keyboard.
- Next Agent That Needs You: press ⌥⌘A to go to each agent waiting on you in turn.
- Allow or Deny an agent's permission request right from its notification.
- Obsidian notes: the editor's Markdown preview now shows [[links]], embedded images and notes, callouts, highlights and tags as Obsidian does.
- Run Again: when a pane's program fails, a bar along its bottom starts it again in the same pane (or press Return), and an agent's pane resumes its session.
- Scheduled Tasks: search the list, press ⌘R to run the selected task or ⌫ to delete it, and see a spinner while a run is going.
- Settings ▸ Notifications can ask macOS for permission straight away, says why the test notification is unavailable when it is, and greys out the sounds of notifications you've turned off.
- Split dividers light up under the pointer, and a double-click makes both sides the same size.
- The menus for new panes and tabs are grouped, with an icon for each kind, and Editor… asks which file to open or starts an empty one.
- The pairing code counts down to when it expires and renews itself, and Copy buttons for pairing and linking links say Copied.
- TUI: a pane whose program failed has Run Again (or Return) and Close along its bottom, and an agent's pane resumes its session.
- TUI: in an empty Group, press Return to open a terminal or a to start an agent.
- TUI: middle-click a tab to close it, and scroll over the tab bar to switch tabs.
- TUI: New Diff Tab… and Split Right with Diff… in the palette open a diff of what's uncommitted, this branch, the last commit, or commits you pick from the history.
- TUI: the palette has Next and Previous Group, more ways to review changes, moving, leaving and closing Groups, and browser splits in every direction.
- TUI: the selected tab's highlight slides along the tab bar, and new Needs You rows pulse once.

## Fixed

- Programs in panes open during an update keep Full Disk Access, instead of losing it until the pane is reopened.
- Linked computers: a computer whose Tailscale restarted, as Unraid's does after an update, no longer shows as asleep while it's on.
- A message sent while a ! command runs no longer disappears from the agent view, taking the command with it.
- A message with pictures, sent while the agent works, now shows in the conversation as soon as the agent takes it, instead of waiting there until it finishes.
- A permission prompt shows what it's asking about, such as the command, even when the conversation hasn't caught up with it yet.
- Agent view: a group of tool calls keeps the last one's description beside it, as the terminal does, not just while it runs.
- Agent view: a message that can't be sent now says so by the message box, with Retry.
- Agent view: Codex's and other agents' tool calls are summed up and read aloud by what they did, not as other tools.
- Agent view: new rows glide into view instead of jumping, and a long reply no longer blanks the conversation for a moment as it arrives.
- Agent view: VoiceOver reads each tool call as one, with what it ran, how it went and whether it's open.
- Attachments put into a message get a space either side, so they don't run into the words around them.
- Browser panes no longer leave a 300 MB copy of the browser on your disk each time Hammock restarts them, and delete the copies they left before.
- Browser panes: passkey and security key prompts now show over the page, instead of opening behind the window and leaving the page stuck.
- Command palette: when nothing matches what you type, it now says so instead of showing an empty list.
- Configure Group: choosing a picture replaces the emoji, and the picture's file chooser opens in the Group's folder.
- Dragging the divider between panes, or a floating pane's edge, keeps the resize pointer the whole way, even over a browser pane.
- Drop a picture anywhere on the agent view to attach it at the end of your message.
- Dropping a folder or a file that isn't a picture or movie on an agent's message box puts its path in the message, rather than asking whether to copy it in.
- Editor and diff panes show an error at the top of the pane, with Retry or Save As…, instead of an alert that held up every window, and their questions open on the pane's own window.
- Find Session no longer sits on “Indexing your sessions…” when a linked computer is offline: it says why, with Retry.
- Finished notifications show the start of the agent's reply.
- hmk tab new --wait and hmk split --wait keep waiting through Hammock restarting, such as for an update, instead of giving up.
- In hmk tui, closing a tab or pane asks first when it would stop an agent at work, and says how to reopen what you closed.
- Markdown previews: a callout with a long title now wraps like text, instead of splitting into narrow columns.
- Permission and join notifications stack with the rest from their pane or Group, and the Dock's count includes join and Hammock Key requests.
- Selecting text in an editor, diff or files pane no longer brings up the Writing Tools button.
- Shut Down Simulator is now in the simulator pane's More menu, away from the header buttons you click often.
- Tab Previews: an agent's tab now previews its conversation as it really looks.
- The agent view's send button stays visible while there's nothing to send.
- TUI: a key after ⌃B that isn't a shortcut now says so, and how to list the ones that are.
- TUI: errors read plainly, without gRPC's wording, and stay on screen long enough to read.
- TUI: pressing Return twice in an empty Group opens one terminal, not two.
- TUI: the sidebar's hint now names the key that opens Commands (⌃B k).
- TUI: when hmkd stops or restarts, the TUI stays open and reconnects, instead of quitting.
- VoiceOver: the icon-only buttons in tabs, pane headers and the browser's toolbar now say what they do, not their symbol's name.
- With Reduce Motion on, notices, the sidebar when it peeks out, the floating-pane shelf and the empty Group's page fade or simply appear instead of sliding, springing or growing.
- With the sidebar hidden, it no longer pops out the moment the pointer brushes the window's left edge, or stays out after the pointer moves away.
- Your phone no longer gets the same notification twice when it's paired with two linked computers.

## Internal

- hmk remote restart: make remote access listen again when your phone or a linked computer can't reach this one.
- Agent view: a glide's point is kept once reached, so the keyboard going down just after can't leave a row to jump into view; the jank probe no longer counts an animated scroll's last frame as a snap.
- AgentMark compiles into the iPhone's widget extension too (HAMMOCK_WIDGETS).
- AgentViews' sides-only clip is the iPhone's; the Mac clips all round as before.
- Daemon: SetMediaView takes max_fps, so a phone can slow a screen's stream while its screen sharing is minimised.
- Files panes, the daemon's side: a new pane kind and its protocol (ListDir, FilesCommand, FilesChanged), with folders watched by FSEvents or inotify and git status colours.
- HammockKit: promptAnswers and HoldPreview, for the iPhone's touch-and-hold menus on Sessions and Groups rows.
- HammockKit: shared helpers for the phones' terminal font size and key bar keys (phone-only).
- Settings ▸ Agent View no longer lists every agent it supports.
- The daemon sends paired phones' Live Activities while you're away (internal/daemon/live.go), and the relay forwards them.
- The Run Again bar's words (Exited N, Couldn't start, Run Again or Resume) come from HammockKit, shared with the iPhone's.
- Touch and hold on Sessions and Groups rows: a UIKit context menu, so tapping the preview opens the pane; roomier preview padding; an agent pane previews its conversation (AgentLease and groupMenuUIImage now public; menus shared as MenuEntry).
