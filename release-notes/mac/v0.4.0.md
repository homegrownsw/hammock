# Mac 0.4.0

## New

- Agents can be approved for 5 minutes with the Hammock Key: tick the box on the Mac's prompt, or choose Approve for 5 Minutes on your iPhone, so a script's few commits or a burst of SSH commands asks once. An agent's window is its own: your programs in that pane still ask.
- Review changes in a diff pane, laid out like a pull request's Files Changed: View ▸ Review Changes (⌥⌘R) shows your branch against its base, uncommitted changes included, or pick what's uncommitted, a commit or a range. Unified or split, whitespace ignored or not, the whole file or just the changes, and a banner to refresh when the code moves on. Comment on a line, a range (drag down the line numbers) or a file, and send your comments to the agent as you write them, or all at once with Send: it answers in the threads and marks them addressed, and you resolve them (Settings ▸ Notifications can tell you when it replies). Comments still open when you close the diff are there when you open it again. Agents open one with hmk diff or the diff_open tool.
- Settings ▸ Tools turns off the browser, simulator, editor, diff viewer or log viewer if you don't use them. Turned off, a tool leaves Hammock's menus, command palette and shortcuts, and agents no longer get its tools, so it stays out of the way of how you already work.

## Fixed

- Closing a simulator pane as its simulator shuts down no longer crashes the simulator helper.
- An editor pane with unsaved changes shows a dot beside the file's name again, with an Unsaved Changes tooltip.
- Opening and closing an iPhone Duo in a simulator pane works again: it had stopped with "the simulator guest helper stopped".
- Settings explain less of what's already clear: shorter descriptions, and fewer of them.
- Start an Agent: a gap between the chosen Group's picture or emoji and its name.
- The menu bar's Remote Access names a linked computer by its own name, not its account's description ("Console and webGui login account" on Unraid).

## Internal

- The daemon tells phones it notified when what a notification was about is resolved (a silent push through the relay's new /clear route; redeploy the relay for it). Phones on an old relay tidy up when the app next connects.
- DaemonConnection can stand in for a daemon (DaemonStandIn), for the iPhone's demo; the Mac doesn't use it.
- The daemon's log names the program behind "scoped a local client … as an agent" (and what started it), once per program, instead of a pid on every connection: a desktop widget polling hmk every few seconds filled it.
