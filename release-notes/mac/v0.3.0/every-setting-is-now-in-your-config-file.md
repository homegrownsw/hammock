Every setting is now in your config file (~/.config/hammock/config), so you can edit it, sync it with your dotfiles or ask an agent to change it: notifications, the sidebar's layout and what it lists, the agent view's fonts, the warning before closing a busy agent, usage limits and the simulator's device frame join the rest. Anything you'd changed in Settings moves there the first time you open this version.
