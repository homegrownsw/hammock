One setting now asks each agent's own service for its usage limits, not just Anthropic for Claude's: Codex, Cursor, Copilot, Gemini CLI, Antigravity, Amp, Droid, Kiro, Kimi Code, Grok, Kilo, Cline and OpenCode Go too, with the sign-in each agent's CLI already keeps on your Mac. Turn it on in Settings ▸ Agents ▸ Ask each agent's service for its usage: only the agents whose limits you show in the sidebar are asked. If you had turned on asking Anthropic for Claude's before, that still asks for Claude's alone until you turn this on.
