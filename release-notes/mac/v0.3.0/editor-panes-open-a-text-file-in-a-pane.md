Editor panes: open a text file in a pane (Quick Open ⌘P, Open File… ⌘O, New Editor Tab ⌥⌘E, or Split Right with Editor ⌃⌘E) and edit it with syntax highlighting, find and replace, Go to Line (⌘L), a git change gutter and optional Vim keys. Every pane and device showing a file edits the same text live, unsaved changes survive restarts, and if an agent changes the file while you're editing it you can reload, keep yours or compare. hmk tui has editor panes too (or hands them to your $EDITOR), and hmk edit and agents can open files in them.
