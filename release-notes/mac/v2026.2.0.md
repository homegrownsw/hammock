# Mac 2026.2.0

## New

- When it's run from its disk image or your Downloads folder, Hammock offers to move itself to Applications, where it can keep running at login and update itself. If you're happy where it is, tick Don't ask again.
- Panes animate as they open and close. To turn pane animations off, use Settings ▸ Appearance ▸ Pane animations.
- The agent view says how long the agent worked on each longer turn, and when it finished, as Claude Code does: “Worked for 30m 31s · done 9:47 AM”. For Claude and Codex.
- Pick a different alert sound for each kind of notification (waiting for you, permission, finished, error, everything else) in Settings ▸ Notifications, from four new Hammock sounds or the Mac's own, or None. That replaces the "Play a sound" switch: if it was off, every kind is set to None.
- Agent view: the model menu also sets Claude's effort level (/effort), and both show as soon as Claude starts, not after its first reply.
- Attachments in the agent view get a number and a chip, with their thumbnail, where the cursor is in your message: move it with the text, or delete it and the attachment waits greyed out in the tray above the message, to click back in.
- Clicking a picture or video in the agent view opens it in Quick Look, with the message's other attachments a press of an arrow key away.
- Commands Claude Code knows are coloured as you type them in the agent view, as they are in Claude Code.
- Messages you've sent show their attachments' numbered chips where they were, and a video you sent shows as a video, not its path.
- New themes: Apricot, Cocoa and Lagoon, which tint the window but leave the terminal plain white or black. Forest is gone: Hammock's green is a forest green now, and Forest moves to it.
- Panes are spaced apart, with rounded corners, by default. Prefer them edge to edge? Choose Compact in Settings ▸ Appearance.
- Pictures you attach are sent smaller, so they cost fewer tokens: Large (1568 px) on this Mac and Medium (1024 px) to other computers and from the iPhone, in Settings ▸ Agent View. Right-click (or touch and hold) one to send it at another size.
- Split ▸ Diff… (and File ▸ New Diff Tab…) asks what to compare before opening: this branch against another, what's uncommitted, a commit or a range. It starts on the branch you're on.
- The Hammock theme's green is a deeper, more forest green, and less minty.
- When an agent uses a browser or simulator pane, you can now see it there: a cursor (or a fingertip on a simulator) glides to where it clicks or taps, the page glows, and a badge says an agent is working there. A page scrolls smoothly to what an agent clicks, and no longer jumps when it was already in view. Take Over stops agents acting in that pane until you hand it back. Turn it off in Settings ▸ Tools.

## Fixed

- The agent view's composer no longer suggests Claude Code's and Codex's built-in commands, like /clear, partway through a message, where they'd be sent as text. Your skills and commands are still offered there.
- A new pane's program now starts at the size the pane is shown at, so programs such as top no longer get resized just after they start and draw at the wrong width until their next update.
- A new Group (⌘N), or a tab you switch to from the keyboard, scrolls into view in the sidebar when it's out of sight.
- Agents and commands that macOS ended as it restarted or shut down are resumed when you log back in, instead of showing “exited with status -1”.
- Agents' clicks in a browser pane no longer miss on pages that load more as you scroll, such as search results and feeds.
- Agents tidying up no longer ask you for permission to close a pane you've already closed: they're told it's gone.
- Control-clicking a link in a terminal now shows its menu (Open Link, Open in Hammock Browser, Copy Link), the same as right-clicking it.
- Pictures and videos sent to an agent are deleted from the Mac's caches a week later, instead of kept forever.
- Renaming this Mac in Settings ▸ Sharing shows the new name at the foot of the sidebar straight away, not the next time Hammock connects.
- Return closes the pane in the alert asking whether to stop what's running in it.
- Screen sharing on iPhone: zoomed in with the phone upright, a Mac's screen is sharp as soon as its height fills the phone, not blurry until you zoom further.
- Scrolling to the end of an agent's conversation no longer leaves it jumping up and down a line.
- Sending a video no longer briefly shows its file's path as a message of yours.
- Settings ▸ Devices: each computer's key and Icon… button line up with the others'.
- Spacious panes in the window's bottom corners round them with the window, concentric with its own corners.
- Spacious panes meet the toolbar and the sidebar, as compact ones do, so the toolbar looks centred; they keep their gap at the window's edges.
- Terminals now report Hammock's own version (TERM_PROGRAM_VERSION, and the Hammock Pane, Browser, Simulator, Screen Sharing and Key helpers), not 0.1.0.
- The agent view no longer stays blank, showing only Working…, while an agent's first tools run after you send a message.
- The tab's name at the top of the window is the same dark text as the tab names in the sidebar.
- The window's toolbar and sidebar look the same whether panes are compact or spacious, and read as one surface, with no edge where the sidebar ends.
- When an agent clicks a link in a browser pane that takes a moment to open its page, such as a search result, it now waits for the page instead of carrying on as if nothing happened.
- When an agent clicks something in a browser pane by its text, it clicks the first match on the page, such as a search result's title, rather than a later link that happens to match exactly, or one covered by something else.
- When an agent goes back or forward in a browser pane, it no longer waits 30 seconds for a page that came straight back from the browser's cache, or when there's nothing to go back to.
- Working… stays at the left under a message you've just sent, instead of moving to the middle.
- Zooming a floating pane, or unzooming it, now animates like any other pane.
- Zooming a pane in or out no longer snaps the terminal into place as it finishes: the terminal takes its new size as the pane starts to move, and the pane grows over it, or shrinks onto it.

## Internal

- The composer is a native text view (NSTextView, UITextView) instead of a TextField; AgentSend.inline pastes each attachment where its chip is, and AgentBlock.rich_text says where they were.
- The README has a demo GIF of the Mac app, recorded by just readme-demo from β on a scratch daemon with made-up Groups (HMK_DEBUG_RECORD, HMK_DEBUG_DIRECTOR); agentreplay sends tool hooks and waits on a closing question.
