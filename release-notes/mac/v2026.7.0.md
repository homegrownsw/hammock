# Mac 2026.7.0

## New

- An agent at rest with subagents still running shows an indigo dot going round its ring, so you can tell it apart from one with only shells running.
- Each Group's browser panes now keep their own logins and cookies, so an agent in one Group can't use another's.
- Hovering over a Group now outlines it with a subtle border.
- Rotate Split: turn a split from side by side to stacked, or back, from the Pane menu or with ⌥⇧⌘D.
- Send Now: right-click a message waiting for Claude to finish and choose Send Now to give it to Claude straight away.
- Shell commands: a command you run with ! shows its output as it runs, and stays open with its output once it's done.

## Fixed

- A config file with a character Hammock can't read in it no longer has its settings ignored, or gets emptied when you change one in Settings.
- A message that the agent never took, such as a ! command you stopped in the terminal, no longer waits in the conversation forever.
- A problem reading this Mac's identity or certificate no longer unpairs your phones and linked computers.
- A program can no longer pass off a file on your Mac as a picture to show it in a pane, to you or to people you share a Group with.
- A program setting a title Hammock couldn't read no longer leaves Hammock, and your phone, waiting for your Groups.
- A sandboxed agent now asks you before it runs or types anything through Hammock, so its commands can't slip out of its sandbox.
- Agents with subagents: messages from the agent view reach the agent even when its terminal is showing a subagent, the message box no longer fills with a subagent's details, and an agent no longer shows as working while only its subagents are.
- Always Allow for This Schedule no longer remembers find or awk, which can run other commands.
- Always Allow for This Schedule no longer remembers a command that could run anything, like bash -c or sudo, for every run.
- An agent that crashes or is killed no longer stays working or waiting for you, and a scheduled run of it ends.
- Changing a setting in two places at once no longer loses one of the changes.
- Clicking a file link in a terminal of a Group on another computer opens that computer's file in an editor pane, not one on this Mac.
- File links from tools like ls, eza and rg open straight away, without asking first.
- Linked computers and shared Groups reconnect within seconds after a network change or sleep.
- Needs You items from another of your computers can be cleared while that computer is asleep, and stay cleared when it wakes.
- Needs You shows all of what an agent asks to run, and Allow answers only the request its card shows, never one that came after it.
- Pasting a lot of text into a simulator pane no longer freezes Hammock.
- Saving in an editor pane keeps the file's hard links, Finder tags and permissions.
- Scheduled tasks follow your Mac's time zone when it changes, without restarting Hammock.
- Symbols your terminal font hasn't got, such as ⌘ and ⌥, no longer overlap the next character.
- When Claude asks a question you can give several answers to, an answer you type yourself is now sent, along with the options you ticked.

## Internal

- Agents can't tell the daemon which panes are on screen, so they can't mark their own finish as seen and keep its notification from you.
- HammockKit: a remote client stops redialling once its Mac refuses its sign-in (only the iPhone connects remotely).
- MCP tools that return pages, files, logs, clipboards, past sessions or others' review comments now say that content is untrusted.
- Review comments are owned by their writer's user id, not their display name: a guest can no longer edit or delete the host's or another guest's unsent comments by signing in with an empty or matching name.
- The daemon reads files clients and agents name (the agent view's files, editor and preview images, hmk show, Group pictures, diffs) only if they're regular files, within their size limit however much they grow, so a device or FIFO can't exhaust its memory or block a connection.
- The daemon's git (diff panes, the editor's gutter marks and file list) runs nothing a repository's own config or attributes name: fsmonitor, filter drivers, external diffs and textconv, hooks, signature checks and lazy fetches are overridden (internal/gitcmd).
- The daemon sends pushes and clears to push.homegrownsw.com even for phones registered at hmk-push.homegrownsw.workers.dev, ahead of turning the workers.dev address off.
