Review changes in a diff pane, laid out like a pull request's Files Changed: View ▸ Review Changes (⌥⌘R) shows your branch against its base, uncommitted changes included, or pick what's uncommitted, a commit or a range. Unified or split, whitespace ignored or not, the whole file or just the changes, and a banner to refresh when the code moves on. Comment on a line, a range (drag down the line numbers) or a file, and send your comments to the agent as you write them, or all at once with Send: it answers in the threads and marks them addressed, and you resolve them (Settings ▸ Notifications can tell you when it replies). Comments still open when you close the diff are there when you open it again. Agents open one with hmk diff or the diff_open tool.
