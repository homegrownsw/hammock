# Mac 2026.3.1

## New

- A default agent: pick one in Settings ▸ Agents, and New Claude Code Tab (or the one you picked) starts it straight away, in the Group's folder, beside New Agent Tab…. It takes ⌥⌘N; New Agent Tab… moves to ⌃⌥⌘N.
- Help ▸ Hammock Documentation (and the command palette, the TUI's palette and hmk docs) opens Hammock's new documentation, with guides and a full reference for the config file, keyboard shortcuts, hmk and the MCP tools.
- Open a tab, Group or pane in a window of its own, to share just that on a call: right-click it and choose Open in New Window, or use the Window menu. It's the same tab, Group or pane, not a copy, and closing the window closes nothing. A tab or pane fills its window; a Group's window has only its own tabs. Agents can open one for you too, as can hmk window open.
- The split buttons and the Split menus can start an agent beside the pane: Agent… picks one, and your default agent's item starts it straight away, in the pane's folder.

## Fixed

- Tabs running Claude Code are named after the session again.
- The Terminal / Agent view switch in a pane's header no longer moves when the agent starts or stops working.

## Internal

- The config file's keys are listed once, in internal/hammockconfig/keys.go, which makes its header (Go's and the Mac's) and the docs' config reference; hmk mcp --list-tools lists every MCP tool as JSON.
- The README's demo GIF keeps the window drawn as active while it records, whatever else takes the focus, and its rounded corners are transparent rather than black.
